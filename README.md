# NotionGlazeV2

Premium Notion-to-Website generator with a focus on design and speed.

## Features
- Dynamic Notion integration
- Multiple stunning themes (Brutal, Minimal, Zen, etc.)
- Dashboard for easy management
- Fast performance with Astro

## Tech Stack
- Astro
- Tailwind CSS (via @notionglaze/ui)
- Cloudflare Services
- Notion API

## Local Development
1. Install dependencies: `npm install`
2. Run dev server: `npm run dev`
